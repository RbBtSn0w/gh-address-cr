# GH Address CR Marketplace

Stable plugin version: 3.23.0.

Install the gh-address-cr runtime separately using pipx or Homebrew.
Register this Git source with an explicit marketplace ref:

```bash
codex plugin marketplace add RbBtSn0w/gh-address-cr --ref marketplace
codex plugin add gh-address-cr@gh-address-cr-community
```

See the source repository documentation for update and recovery instructions.
