常见问题

为真实的
PR 工作流而建。

gh-address-cr 会执行 AI 代码评审吗？

不会。它负责评审解决和完成门禁。你选择的评审生产器或编程 Agent 提供发现，gh-address-cr 负责跟踪、验证、回复、解决和门禁。

PR 发生变化时会怎样？

验证证据绑定当前 commit 和变更文件。新的 head revision 或 Stack 拓扑变化会使旧证据失效，必须刷新后才能继续。

只能和 GitHub Copilot 一起使用吗？

不能。它的本地优先 CLI 和结构化 Agent 协议也适用于 Codex、Claude 及其他兼容 Agent。
